# 目的と範囲

## 現在の範囲

- Bash / Zsh のログインシェル選択と、それに対応する rc の設置を一つの操作で行う。
- 共通の alias・環境変数と、シェル固有の履歴・プロンプト・補完を管理する。
- 既存 rc を回復可能な状態で残す。
- 導入手順は Arch Linux と paru を前提とする。他の OS の対応保証はない。

根拠: [README](../../README.md)、[シェル切替要件](../audits/20260925-01-shell-switch/requirements.md)。

## Mac 拡張の確定条件

利用者の指定は「Mac 標準の Zsh のみ対応」「追加ツールは極力不要」。これは今後の要件で、現在の実装済み機能ではない。Mac 上の Bash 対応、特定のパッケージマネージャ導入を前提とした拡張は含めない。具体的な受入条件と検証状況は Beads の Mac 対応課題 `shelld-x94`に置く。

## 責任の境界

- shelld はユーザーのシェル設定を扱う。OS 全体の構築、Docker / Kubernetes の導入・運用は担当しない。
- [private](03_DOMAIN_MODEL.md) の個人設定や、外部コマンドの実行結果は利用環境に依存する。
- 実機のログインシェル変更やソフトウェア導入は、検証用の隔離実行とは区別する。
