# 意思決定

独立した ADR 集はない。既存の要件・実装・作業規約へ辿れる形で、影響の大きい方針だけを記す。

| 状態 | 決定と影響 | 根拠・理由 |
| --- | --- | --- |
| 採用済み | Bash / Zsh の apply はログインシェル選択後に rc を設置する | [既存要件](../audits/20260925-01-shell-switch/requirements.md)。設定だけ適用される状態を防ぐ |
| 採用済み | 未導入シェルの導入は paru を使う | [README](../../README.md)、[導入実装](../../install/change-shell.sh)。Arch Linux 前提で、選定時の詳しい比較記録はない |
| 採用済み | rc の置換前に一意なバックアップを保存する | [既存要件](../audits/20260925-01-shell-switch/requirements.md)。元の内容を復元可能にする |
| 採用済み | 進行中の作業記録は Beads、長期理解資料はこのディレクトリに分ける | [AGENTS.md](../../AGENTS.md)。旧 Markdown log は履歴として保持する |
| 要件確定・未実装 | Mac 拡張は標準 Zsh のみ、追加ツールは極力不要とする | 利用者指定。詳細な実装・受入条件は Beads の Mac 対応課題 `shelld-x94`が所有する |
| 未決 | Mac の対象 OS バージョン、標準コマンドとの差分吸収、検証環境 | 実装担当者が Mac 対応課題で確認する。現時点で対応済みとは扱わない |

OS 分岐の置き場所など実装方式は未決で、既存コードから将来の設計方針を確定しない。
